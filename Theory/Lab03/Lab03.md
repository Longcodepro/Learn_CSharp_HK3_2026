# Lab03 – Array và Collections

## Mục tiêu

Thực hành các cấu trúc lưu trữ dữ liệu phổ biến trong C#:

- Khởi tạo và duyệt mảng.
- Tìm vị trí, lọc và sắp xếp phần tử với `Array`.
- Sử dụng lambda để lọc dữ liệu.
- Làm việc với `ArrayList`, boxing và unboxing.
- Sử dụng `List<T>` để lưu dữ liệu có kiểu an toàn.

## File chính

| File | Nội dung |
| --- | --- |
| `LearnArray.cs` | Các thao tác với mảng |
| `LearnArrayList.cs` | `ArrayList`, boxing/unboxing và sắp xếp |
| `LearnList.cs` | Khởi tạo và duyệt `List<T>` |

## Chạy project

Project có nhiều hàm `Main`. Chọn bài cần chạy làm startup object trong IDE trước
khi thực thi.
