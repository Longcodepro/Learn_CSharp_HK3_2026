# Basic – C# Fundamentals

## Mục tiêu

Ôn các kiến thức nền tảng trước khi làm các lab:

- Ép kiểu tường minh và cách dữ liệu thay đổi khi chuyển kiểu.
- Khai báo class, property, constructor và method.
- Bài toán hình tròn, hình chữ nhật, đếm chữ số và sinh số ngẫu nhiên.
- Kế thừa, đóng gói và xây dựng các lớp nhân viên.

## Cấu trúc

| Thư mục | Nội dung |
| --- | --- |
| `01_Casting` | Thực hành explicit casting |
| `Class` | Các bài tập class và object |
| `Inheritance` | Các bài tập kế thừa và quản lý nhân viên |

## Chạy project

Project chứa nhiều bài có entry point riêng. Chọn class cần chạy trong IDE hoặc
cấu hình `StartupObject` trước khi chạy toàn project.
